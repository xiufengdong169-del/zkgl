# 用户演示与测试交付总结

更新时间：2026-08-23

本文档用于把当前阶段开发成果交付给业务用户先行演示和测试。当前策略是先在本地电脑跑通可视化演示与自动化验收，远程服务器正式部署暂缓。

## 1. 当前交付结论

当前系统已具备本地演示与主体流程用户测试条件：

- 可通过本地浏览器打开演示界面。
- 左侧菜单已提供“演示测试中心”，用于引导非技术用户按主流程查看。
- 主体业务链路已形成页面级闭环：客户线索、项目立项、审批、投标、合同、项目实施、财务收支、结算保证金、文件、报表、系统管理。
- 演示模式使用样例数据，不连接生产数据库，不访问远程服务器。
- 本地完整联调模式已连接本机 MySQL，完成真实 API 读写验证；入口为 `http://127.0.0.1:5173/`，API 通过本地认证代理访问 `http://127.0.0.1:4180/api`。
- 自动化验收覆盖类型检查、API 测试、Web 测试、前端构建、安全扫描、需求一致性、部署资产、备份资产、初始化资料和本地演示包。

## 2. 本地演示入口

在项目根目录执行：

```powershell
npm run demo:local
```

终端显示本地地址后，用浏览器打开：

```text
http://127.0.0.1:4173/
```

如 4173 端口被占用，以终端实际输出地址为准。

打开页面后，建议优先点击左侧菜单：

```text
演示测试中心
```

也可以直接访问：

```text
http://127.0.0.1:4173/demo
```

如果浏览器打不开 `127.0.0.1` 或 `localhost`，改用文件版演示包：

```powershell
npm run demo:file
```

生成后双击打开：

```text
C:\Users\27787\Desktop\zkgl\.tmp\zkgl-file-demo\index.html
```

或在浏览器地址栏输入：

```text
file:///C:/Users/27787/Desktop/zkgl/.tmp/zkgl-file-demo/index.html#/demo
```

## 3. 建议用户测试顺序

建议按以下顺序查看：

1. 演示测试中心：先理解当前可演示范围、自动化复核口径和暂未冒充完成的真实环境事项。
2. 工作台：查看经营指标、待办审批、我的项目、提醒消息和导出任务。
3. 客户管理、市场线索：查看客户、联系人、拜访、线索和跟进。
4. 项目管理、审批待办：查看立项申请、项目详情、审批流和审计记录。
5. 投标管理、合同管理：查看投标申请、任务检查项、友商配合、合同、变更和履约节点。
6. 项目实施：查看阶段、进展、风险、成果、验收和异常提醒。
7. 收支管理、结算保证金：查看开票、收款、核销、付款、报销、合作方结算、保证金和结项。
8. 项目文件、统计报表、系统管理：查看文件版本、敏感字段、经营统计、参数和基础资料。

## 4. 当前已完成的主体能力

- 账号与权限：菜单权限、路由守卫、内部账号启停、角色权限、数据范围和敏感字段控制。
- 客户与线索：客户、联系人、拜访、市场线索、跟进记录。
- 项目立项：立项申请、驳回重提、审批通过后生成正式项目编号。
- 投标管理：投标申请、投标任务、检查项、结果记录、友商配合。
- 合同管理：合同、合同变更、履约节点、暂定金额确认、状态联动。
- 项目实施：提前启动、补签提醒、阶段、进展、风险、变更、成果、验收。
- 财务收支：开票申请、销项发票、收款、核销、付款、报销、日常采购。
- 结算保证金：合作方结算方案、结算单、保证金、项目结项和遗留事项。
- 文件与导出：文件版本、下载安全、后台导出任务和过期控制。
- 报表与工作台：经营指标、项目统计、回款、利润和待办提醒。
- 运维资产：腾讯云轻量服务器部署模板、Nginx、systemd、备份、恢复、初始化资料和预检脚本。

## 5. 自动化测试与复核口径

当前主验收命令：

```powershell
npm run verify:acceptance
```

该命令覆盖：

- TypeScript 类型检查。
- API 单元与集成测试。
- Web 单元测试。
- 前端生产构建。
- 源码敏感信息扫描。
- V2.2 需求基线一致性校验。
- 前端构建产物安全检查。
- 腾讯云轻量服务器部署资产校验。
- 备份、恢复、初始化资料和对象恢复清单校验。
- 本地演示包和本地用户测试文档校验。
- 生产依赖漏洞扫描。

当前测试基线：

- API：90 个测试文件 / 482 条测试。
- Web：10 个测试文件 / 64 条测试。

## 6. 当前仍需真实环境完成的事项

以下事项不能在本地演示阶段冒充完成：

- 腾讯云轻量服务器正式部署、HTTPS、Nginx 反向代理、systemd 托管和真实认证适配。
- 服务器 MySQL 8.0 空库初始化和正式账号资料导入。
- 30 用户现场性能压测。
- 数据库、项目附件和后台导出文件恢复演练。

## 7. 本阶段下一步重点

为了尽快交付用户测试，后续优先级调整为：

1. 保持本地演示入口稳定可打开。
2. 完善演示测试中心和主流程页面，让非技术用户能直接理解系统。
3. 每轮改动后执行自动化验收，确保主线不被破坏。
4. 本地 MySQL 条件具备后，启动真实 API、本机认证代理和前端联调。
5. 用户确认本地界面和流程后，再进入腾讯云轻量服务器部署。
